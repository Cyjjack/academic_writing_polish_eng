# Author editing preferences: what the author tends to reject

- 段首 this change 指向多个可能对象（G2 #98）。能唯一回指时保留代词。
- 并列引文之间强加转折或比较（G3 #112）。比较对象、指标及条件确实相同才使用对比句。
- 用 improved 或 refined 遮住方法到底改了什么（F #198）。请作者确认改进的具体操作；缺依据时不宣称改进。
- 用“observed”笼统覆盖未展示的响应（F #258）。有独立数据时可正常使用这个词。
- 为一处使用引入简称（F #491），或在摘要及结论堆积首次阅读者无法解释的符号（G3 #102、682）。通行且反复使用的有定义术语可以保留。
- 仅凭边缘数值、没有物理含义的频率或没有定义的虚线作解释（G2 #318，F #746）。追问定义和来源，不补机制。
- G3 #632 的人称意见明确针对该土木稿件；图中字体、文献样式亦属排版。以上均不设跨学科禁词。
