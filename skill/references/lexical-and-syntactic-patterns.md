# 意图与句法决策
有明确参照组 → 以响应量作主语，比较对象放在相邻短语；若前后值属于同一试件，写时间或加载阶段的变化，不能转写成组间差异。compared with/to 的合并检索见证据库，不据此判定介词优劣。
方法目的 → 前句出现明确的工程难题时，可随后以模型或试验为主语说明实现手段。to this end 只用于手段确实服务于前述目标。连续步骤可复用已定义的构件名自然衔接。
定义句 → RC-02 的主动式被改为以传播时间作主语的被动式，并保留到 EQS。仅当定义对象是当前主题时采用。术语改变物理含义时暂停润色，先核查比值的分子、分母及位置（RC-01）。
解释 → may be attributed to 保留候选机理。can 表能力或可行性时不能替换 may。indicate 的主语宜为观察或分析结果；demonstrate、confirm 须有相称证据。
结果定位 → as shown in 适用于图中能直接查到的现象。图上没有给出机制证据时另起解释句。主被动选择取决于当前主题是方法执行者、模型构造还是响应量。
